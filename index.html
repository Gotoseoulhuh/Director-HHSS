유튜브 링크로 열기

공개 또는 일부공개이며 퍼가기가 허용된 영상 링크를 넣어 주세요. 영상은 유튜브 플레이어로 그대로 재생되고, 메모에는 캡처 대신 시간과 핀 위치가 기록됩니다(화면 공유 없음). 가로·세로 비율은 자동으로 알아냅니다.

서버 설정 (관리자)

Supabase의 프로젝트 URL과 anon(public) 키는 공개용이라 배포 파일에 들어가도 됩니다. 관리자 비밀번호는 여기 넣지 않고 로그인 화면에서만 씁니다. service_role 키는 절대 넣지 마세요.

비워 두면 지금 열려 있는 주소를 씁니다. 파일(file://)로 연 상태에서는 꼭 채워 주세요.

클라이언트 검수 만들기

지금 열어 둔 영상으로 서버에 프로젝트를 만들고, 클라이언트용 링크와 아이디·비밀번호를 만듭니다. 클라이언트는 링크를 열어 로그인한 뒤 영상을 보며 포인트를 찍고, 빠른 수정 요청을 누르면 관리자 화면에 들어옵니다.

링크를 연 사람은 이 아이디·비밀번호를 넣어야 검수 화면이 보여요. 이 프로젝트에서만 쓰입니다.

도움말 — 이렇게 검수해 주세요

  1. 이름 적기 — 위쪽 검토자 칸에 이름을 적어 주세요. 누가 남긴 요청인지 표시돼요.
  2. 영상 보기 — ▶ 버튼이나 스페이스바로 재생·정지해요. 영상 파일을 받으셨다면 그 파일을 화면에 끌어다 놓으세요.
  3. 고칠 곳 클릭 — 화면에서 고칠 곳을 클릭하면 영상이 멈추고 빨간 점이 찍혀요. 유튜브 영상은 처음 한 번 '이 탭 공유' 창이 뜨는데, 공유(허용)를 누르면 그 장면 사진이 함께 전달돼요. (원치 않으면 취소해도 돼요)
  4. 내용 적기 — 오른쪽 칸에 바로 적고 Enter. 자주 쓰는 문구 버튼을 눌러도 돼요.
  5. 보내기 — 다 하셨으면 오른쪽 위 빠른 수정 요청을 눌러 주세요. 누르기 전에는 전달되지 않아요. 더 적고 다시 누르면 새로 쓴 것만 보내져요.

보내기가 안 될 때: 내보내기 → 메모 전체 복사를 누른 뒤 카톡에 붙여 넣어 보내 주세요.
