# Director's Board · HHSS

영상을 보다가 고칠 곳을 **화면에서 클릭**하면 그 자리에 핀·타임스탬프(영상 파일이면 캡처까지)가 붙은 수정 요청이 만들어지는 검수 도구입니다.
관리자(로그인)가 프로젝트를 만들어 **링크 + 아이디·비밀번호**를 보내면, 클라이언트는 로그인해 영상을 보며 주석을 남기고 **빠른 수정 요청** 버튼으로 관리자 화면에 보냅니다.

- 앱 전체가 `index.html` 한 파일 (HTML + CSS + JS, 프레임워크·빌드 없음)
- 영상 파일은 사용자 PC 밖으로 나가지 않음 (서버에는 시간·좌표·글·그림·캡처 이미지만 저장)
- 서버: Supabase (Postgres + RLS), 호스팅: GitHub Pages **https://gotoseoulhuh.github.io/Director-HHSS/** — 설정은 [SETUP.md](SETUP.md)

## 실행

| 방법 | 언제 |
|---|---|
| **웹 주소로 열기** (GitHub Pages) | 평소. 유튜브 검수·클라이언트 링크는 이 방법에서만 동작 |
| `검수기 실행.cmd` 더블클릭 | 아직 배포 전이거나 오프라인. Node.js가 있는 Windows PC에서 `http://127.0.0.1:8765/` 로 열림 |
| `index.html` 더블클릭 | 영상 **파일** 검수만. 유튜브 재생 불가(file://) |

## 기능

**검수**
- 포인트: 화면 클릭 → 핀 + 시간 + 1280px 캡처. 핀은 **드래그로 이동**, **우클릭으로 포인트만 제거**(글은 유지)
- 그리기: 드래그로 그림 주석, 여러 획, 획 되돌리기
- 핀을 찍으면 입력칸에 바로 커서가 들어가 타이핑하면 됨. 메모만(M), 자주 쓰는 문구(Q/W/E/R, 입력 중에는 Alt+Q/W/E/R), 수정·삭제·Ctrl+Z 되돌리기(이동·제거·삭제 모두)
- 재생·배속·5초/1프레임 이동. **FPS 자동 판별**: MP4/MOV는 파일 정보에서(가변 프레임이면 평균 표시), 그 외는 재생 중 측정(≈), 유튜브는 "알 수 없음 · 기본값 기준"으로 솔직하게 표시 + 직접 지정 가능
- 유튜브 링크 재생(화면 공유 없음): 영상은 유튜브 플레이어로 그대로 보고, 메모에는 **시간·핀 위치·그림**만 기록. 가로·세로 비율 자동 감지. `← →`가 1프레임(Shift: 5초)
- HEVC(아이폰·카톡 원본) 등 크롬이 못 트는 파일은 원인과 해결책을 화면에 안내

**저장·공유**
- 브라우저 자동 저장(IndexedDB) + 프로젝트 JSON 저장/열기
- 관리자 로그인(Supabase Auth, 어느 PC에서나) / 클라이언트 로그인(프로젝트마다 아이디·비밀번호, 서버에는 해시만)
- 클라이언트 화면: 관리 메뉴 없음, **빠른 수정 요청**(누를 때만 전송, 안 보낸 개수 표시), 내보내기(대체 경로), 큰 **도움말** 버튼
- 관리자 메모는 서버 자동 저장, 상태 표시(서버 저장됨 / 저장 중 / 오프라인 임시 저장 / 실패 재시도)
- 내보내기: 카톡용 텍스트(시간·좌표·유튜브 시점 링크), 노션용, **슬라이드형 공유 HTML**(큰 캡처 + 주석 + 댓글 + 필름 롤, 댓글 포함 재저장 — 유튜브 프로젝트는 캡처 대신 그 시점의 유튜브 영상을 바로 보여줌), 인쇄/PDF

## 운영 흐름

```
관리자  로그인 → 영상 열기 → 서버 ▾ → 클라이언트 검수 만들기(아이디·비밀번호) → 안내 문구 복사 → 전달
클라이언트  링크 열기 → 로그인 → 이름 → (파일 프로젝트면 받은 영상 열기) → 클릭·메모 → 빠른 수정 요청
관리자  서버 ▾ → 서버 프로젝트 열기 → 요청이 작성자 이름과 함께 표시 (8초마다 갱신)
```

## 폴더

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 (관리자·클라이언트 공용, 주소 `#p=`가 있으면 클라이언트). 배포 전에 `SERVER_DEFAULT` 두 값만 채움 |
| `supabase/schema.sql` | 테이블·RLS·함수. Supabase SQL Editor에서 한 번 실행 |
| `SETUP.md` | Supabase(관리자 계정 포함)·GitHub Pages 설정, 한계 |
| `사용방법.md` | 화면 조작 설명 |
| `HANDOFF.md` | 구조·구현 상태·다음 작업 (개발자용) |
| `review-server.cjs`, `검수기 실행.cmd` | 로컬 실행 도우미 (Node 내장 모듈만) |
| `review.test.cjs` | Chrome DevTools Protocol 기반 자동 검사 (npm 패키지 없음) |
| `tests/` | Playwright 기반 검사(선택): 핀 드래그·FPS 판별·서버 동기화(모의 Supabase) |
| `H264로_변환.bat`, `유튜브_링크로_받기.bat` | ffmpeg / yt-dlp 도우미 (선택) |

## 개발 검증

```powershell
node review-server.cjs --no-browser      # 서버
node review.test.cjs                     # 다른 터미널. CHROME=경로 로 크롬 위치 지정 가능
node review.test.cjs --youtube           # 실제 유튜브 재생·핀·프레임 이동까지 (인터넷 필요)
```

Playwright 검사(선택): `npm i playwright` 후 `node tests/t_dboard1.js`, `node tests/t_sync.js` (Chrome 경로는 파일 상단 `executablePath`).
